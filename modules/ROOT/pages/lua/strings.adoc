= Strings, numbers, and patterns

`..` joins strings.
A number is joined when Lua can read it as a numeral.
`#name` is the length in bytes, which for the ASCII names in an auction row is the length in characters.

[source,lua]
----
local line = "item " .. tostring(itemID)
local n = tonumber("12")
local whole = math.floor(price / 10000)
local text = string.format("%d x %s", count, name or "?")
----

`string.format` follows the usual `printf` conversions: `%d` for a whole number, `%s` for a string, `%q` for a quoted Lua string, `%%` for a percent sign.

== Money as copper

Price fields in this build are copper counts.
The type names are `BigUInteger` and `WOWMONEY`.
One gold is 10000 copper.
One silver is 100 copper.

[source,lua]
----
local function formatCopper(copper)
  copper = copper or 0
  local gold = math.floor(copper / 10000)
  local silver = math.floor((copper % 10000) / 100)
  local rest = copper % 100
  return string.format("%dg %ds %dc", gold, silver, rest)
end
----

The client also formats money.
`C_CurrencyInfo.GetCoinText(amount)` takes a `WOWMONEY` amount and returns a string.
The separator defaults to `", "`.

[source,lua]
----
local text = C_CurrencyInfo.GetCoinText(buyoutPrice)
----

== Patterns

Lua patterns are not regular expressions.
The character classes are shorter, and `%` is the escape.

[cols="1,2"]
|===
|Pattern |Matches

|`.`
|any byte

|`%d`
|a digit

|`%a`
|a letter

|`%s`
|a space

|`%w`
|a letter or digit

|`+`
|one or more of the previous

|`*`
|zero or more

|`-`
|the shortest run

|`()`
|a capture
|===

[source,lua]
----
local itemID = string.match(link or "", "item:(%d+)")
itemID = tonumber(itemID)
----

`string.match` returns the captures, or the whole match when there are no captures.
`string.find` returns the start and end indexes, then the captures.
`string.gsub` replaces.

[source,lua]
----
local plain = string.gsub(name or "", "^%s+", "")
----

A pattern that came from a player, or from an item name, should pass through `string.gsub(text, "([%%%^%$%(%)%.%[%]%*%+%-%?])", "%%%1")` before it is used as a pattern.
Otherwise a parenthesis in the name is a pattern, not a character.

== Color and links

Chat and font strings read a small markup.

[source,lua]
----
local gold = "|cffffd100"
local line = gold .. "Hello|r"
----

`|c` starts a color.
The next eight digits are alpha, red, green, and blue.
`|r` restores the previous color.
`|T` draws a texture.
`|H` and `|h` wrap a link: the first piece is the payload, the text between `|h` and `|h` is what the player sees.

`C_Item.GetItemInfo` returns `itemName` and then `itemLink`.
It can return nothing when the client has not cached that item yet.

[source,lua]
----
local itemName, itemLink = C_Item.GetItemInfo(2589)
if itemLink then
  print(itemLink)
  local itemID = tonumber(string.match(itemLink, "item:(%d+)"))
end
----

The link is safe to hand to `SetText`.
The pattern reads the item id back out.
