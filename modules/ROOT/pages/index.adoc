= Addon guide

World of Warcraft runs addon code in *Lua 5.1*.
That has been the language of the addon environment for the life of the game, and it is the language of this Classic client.
A script written for a later Lua, with `goto`, the `//` operator, bitwise operators, or `<const>`, is a different language.

This guide is that language on {display-name} {build-version}, interface {interface}, plus the calls in the API browser for this snapshot.
The language reference is the xref:lua/manual.adoc[Lua 5.1 manual].
