= Addon files

An addon is a folder in `Interface/AddOns`.
The folder name and the TOC name match.

[source,text]
----
Interface/AddOns/PriceLog/PriceLog.toc
Interface/AddOns/PriceLog/PriceLog.lua
----

For this {display-name} client the game folder is `{client-folder}`.
The interface number of the snapshot in Libram is {interface}.
`GetBuildInfo` is a global in this export.
One of its returns is `interfaceVersion`.
Put that number in the TOC for the client you are loading.

`PriceLog.toc`:

[source,text,subs="+attributes"]
----
## Interface: {interface}
## Title: Price Log
## Notes: Records auction prices from this client.
## SavedVariables: PriceLogDB
PriceLog.lua
----

`## Interface` is the client the TOC was written for.
`## SavedVariables` names the global the client saves.
The Lua file is listed after the headers, one file per line, in load order.

== The Lua file

The client runs the file once, as a chunk, when the addon loads.
Locals at the top of the file live for the whole session.
The saved global is created if this is the first run.

[source,lua]
----
local ADDON_NAME = ...

PriceLogDB = PriceLogDB or {
  scans = {},
}

local frame = CreateFrame("Frame")
frame:RegisterEvent("ADDON_LOADED")
frame:SetScript("OnEvent", function(self, event, name)
  if name ~= ADDON_NAME then
    return
  end
  PriceLogDB.scans = PriceLogDB.scans or {}
end)
----

`...` in the main chunk is the addon name, then the addon table.
The first value is the folder name.

== Load order

`## Dependencies: Blizzard_AuctionHouseUI` asks the client to load that addon first.
Price Log does not require the auction UI addon.
It registers for auction events itself.
Optional dependencies use `## OptionalDeps`.

== A slash command

[source,lua]
----
SLASH_PRICELOG1 = "/pricelog"
SlashCmdList.PRICELOG = function(message)
  local count = PriceLogDB.scans and #PriceLogDB.scans or 0
  print("Price Log has " .. count .. " saved scans.")
end
----

`SLASH_<NAME>1` is the command text.
`SlashCmdList.<NAME>` is the function.
`<NAME>` is the same token in both, and it is not the addon folder name unless you choose that.

== What not to put in the TOC

Do not list a library you have not put in the folder.
Do not set `## SavedVariables` to a name you then declare `local`.
The client saves the global.
